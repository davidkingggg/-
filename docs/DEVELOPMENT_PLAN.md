# 开发计划 (Development Plan)

采用“文档先行 + 分块开发 + 每块测试”的方式进行 Vibe Coding。
每个阶段开发完成后，需及时记录 `CHANGELOG.md`。

## 全局规范
> **阶段结束检查：**
> 1. 更新 CHANGELOG.md
> 2. 运行 npm run lint
> 3. 运行 npm run build
> 4. 运行 Prisma migration
> 5. 浏览器打开相关页面测试
> 6. 按 TEST_PLAN.md 完成对应模块测试

## 第 1 阶段：项目骨架
### 完成内容：

* TypeScript

## 第 8 阶段：数据工具与运维加固
### 第 8A 阶段：数据质量检查仪表盘
* 数据质量检查页面 `/data-quality`
* 重复供应商、缺少联系人/评分、缺失 compareKey 等检查
* 按严重程度/检查项/品类筛选
* CSV 导出检查结果

### 第 8B 阶段：本地数据库备份与恢复
* `/backup` 页面，创建 SQLite 数据库备份
* 恢复前自动创建 `before-restore` 安全备份
* 文件名白名单 + 路径穿越拦截 + 确认短语校验

### 第 8C 阶段：CSV 导入导出加固
* CSV 模板下载（报价明细 + 供应商预研模板）
* 报价导入错误报告增强（结构化中文错误）
* CSV 导出统一化（UTF-8 BOM、中文表头、标准转义）

### 第 8D 阶段：数据质量增强、备份基线、回归样例、归档管理
* 8D-1：数据质量检查 CSV 导出
* 8D-2：备份恢复运维基线补齐
* 8D-3：CSV 导入导出回归样例库
* 8D-4：归档数据统一查看与恢复 (`/archive`)

### 完成标准：
* 数据质量检查覆盖核心数据问题
* 备份可创建、可恢复，安全机制有效
* CSV 导入导出回归样例全部通过

* **全部阶段检查及 TEST_PLAN.md 清单均验证通过**

## 第 9 阶段：供应商导入、附件中心、品类资料包
### 第 9A 阶段：供应商 CSV 正式导入
* 新增 `POST /api/suppliers/import`，接收 JSON `{ csvText }`
* 浏览器端读取 CSV 文本，不做服务器文件上传
* 严格事务模式：全量校验通过后统一写入
* 供应商名称标准化比较，重名报错
* 联系人规则：姓名空 + 联系信息非空报错；全空不创建
* 导入失败返回中文错误报告 + 错误 CSV 下载
* `/data` 页面新增"供应商 CSV 导入"入口
* 供应商模板 `supportedImport` 改为 `true`

### 第 9B 阶段：附件路径中心
* 新增 `/attachments` 统一附件路径管理页面
* 支持按关联类型筛选，支持显示已归档记录
* 编辑弹窗（关联类型和关联 ID 不可编辑）
* 关联对象列支持跳转到对应详情页
* 页面明确说明仅维护路径记录，不处理真实文件

### 第 9C 阶段：品类商务支持资料包
* 新增 `/category-package` 页面，按品类聚合 6 个区块
* 品类概况、推荐供应商、报价概览、评分与风险、销售资料、老板决策
* 支持 Markdown 预览/源码切换、复制到剪贴板
* Markdown 和 CSV 双格式导出
* `includeNotes` 控制内部备注可见性

### 完成标准：
* 供应商 CSV 可正式导入，错误报告完整
* 附件路径可统一管理和筛选
* 品类资料包覆盖 6 个区块，导出正常
* 未新增数据库表、未修改 Prisma schema、未新增 migration、未修改 seed
* **全部阶段检查及 TEST_PLAN.md 清单均验证通过**
