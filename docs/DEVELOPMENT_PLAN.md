# 开发计划 (Development Plan)

采用“文档先行 + 分块开发 + 每块测试”的方式进行 Vibe Coding。
每个阶段开发完成后，需及时记录 `CHANGELOG.md`。

## 全局规范
> **阶段结束检查：**
> 1. 更新 CHANGELOG.md
> 2. 运行 npm run lint
> 3. 运行 npm run build
> 4. 运行 Prisma migration
> 5. 浏览器打开相关页面测试
> 6. 按 TEST_PLAN.md 完成对应模块测试

## 第 1 阶段：项目骨架
### 完成内容：
* Next.js 项目初始化
* TypeScript
* Tailwind CSS
* Prisma + SQLite
* 中文后台布局
* 左侧导航
* 空页面路由

### 完成标准：
* 本地可以打开系统
* 所有菜单能进入页面
* 数据库文件可以生成
* **通过阶段结束检查**

---

## 第 2 阶段：基础主数据
### 完成内容：
* 系统设置基础页面（仅做简单的键值配置，不做复杂功能）
* 品类管理
* 人员管理
* 供应商管理
* 供应商联系人
* 种子数据

### 完成标准：
* 能新增、编辑、归档供应商
* 供应商可以绑定品类
* 供应商可以有多个联系人
* 有 10 个预置品类
* 有 8 家虚拟供应商
* **通过阶段结束检查**

---

## 第 3 阶段：报价模块
### 完成内容：
* 报价单
* 报价明细
* 报价来源记录
* 报价 CSV 导入导出

### 完成标准：
* 一张报价单可以有多个产品明细
* 报价可以关联供应商和品类
* 可以记录 PDF/Excel/图片路径（附件关联）
* 可以导出报价数据
* **通过阶段结束检查**

---

## 第 4 阶段：报价对比
### 完成内容：
* 按品类对比
* 按产品名称/型号（基于 compareKey）对比
* 最低价、最高价、平均价
* 同规格多供应商对比

### 完成标准：
* 能筛选某个品类
* 能筛选某个产品/型号
* 系统自动计算最低、最高、平均价格
* **通过阶段结束检查**

---

## 第 5 阶段：评分和考察记录
### 完成内容：
* 供应商评分
* 自动计算总分
* 自动生成评级
* 手动调整评级
* 调研/考察记录

### 完成标准：
* 评分绑定供应商 + 品类，且有明确时间及评分人
* 总分自动计算
* 评级自动生成
* 供应商详情页能看到评分历史和考察记录
* **通过阶段结束检查**

---

## 第 6 阶段：流程看板
### 完成内容：

* 采购执行流程

### 完成标准：
