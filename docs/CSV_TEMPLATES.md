# CSV 导入导出模板

固定导入导出格式，避免字段混乱和解析错误。自 Phase 8C 起增强报价明细 CSV 导入、模板下载和错误报告；Phase 9A 起供应商 CSV 导入正式上线。

## 1. 模板下载

系统提供本地模板下载接口：

| 模板 | 地址 | 状态 |
|---|---|---|
| 报价明细导入模板 | `/api/csv-templates?type=quote-items` | 支持导入 |
| 供应商导入模板 | `/api/csv-templates?type=suppliers` | 正式支持（Phase 9A） |
| 采购审批导入模板 | `/api/csv-templates?type=purchase-processes` | 支持导入 |

所有模板均使用 UTF-8 BOM，便于 Excel 正确识别中文表头。

## 2. 报价明细导入模板

这是第 8C 第一版正式支持导入的模板。

| 字段 | 必填 | 说明 |
|---|---|---|
| 报价单编号 | 否 | 相同编号会合并为同一张报价单 |
| 报价单名称 | 否 | 报价单标题 |
| 报价文件路径 | 否 | 非空时创建 QuoteSheet 附件记录；不检查文件是否真实存在 |
| 供应商名称 | 是 | 系统中不存在时会自动新增供应商 |
| 品类 | 是 | 系统中不存在时会自动新增品类 |
| 报价日期 | 是 | `YYYY-MM-DD`，也支持 `YYYY/MM/DD` |
| 报价阶段 | 否 | `初次报价 / 二次议价 / 最终确认价 / 量大优惠价` |
| 报价来源类型 | 否 | `微信 / 图片 / PDF / Excel / 口头 / 其他` |
| 对比规格标识 (compareKey) | 否 | 用于同规格横向对比；为空时默认使用“品类 + 产品名称” |
| 产品名称 | 是 | 产品名称 |
| 型号规格 | 否 | 型号或规格 |
| 单位 | 否 | 如 `台`、`套`、`米` |
| 报价 | 是 | 数字格式 |
| 是否含税 | 否 | 空值默认为否 |
| 税率 | 否 | 支持 `13%`、`13`、`0.13` |
| 是否含运费 | 否 | 空值默认为否 |
| 最小起订量 | 否 | 整数 |
| 交期 | 否 | 文本 |
| 付款条件 | 否 | 文本 |
| 质保期 | 否 | 文本 |
| 价格备注 | 否 | 文本 |

### 报价单合并规则

1. 如果 CSV 中存在相同的“报价单编号”，则合并归为同一个 QuoteSheet。
2. 如果没有提供“报价单编号”，则按照 `供应商 + 品类 + 报价日期 + 报价阶段` 自动判断是否归为同一张报价单。
3. 同一“报价单编号”下的供应商、品类、报价日期、报价阶段、报价来源类型必须一致；如与 CSV 内其他行或系统已有报价单冲突，本次导入整文件失败。

### 事务规则

- 导入前先完整校验所有行。
- 只要存在任何错误，本次导入全部失败。
- 失败时不会写入 QuoteSheet、QuoteItem 或 Attachment。
- 前端展示中文错误表格，并可下载错误报告 CSV。

## 4. 采购审批导入模板

采购审批模板字段如下：

| 所属公司 | 实际金额 | 所属项目 | 详细说明 | 支付对象 | 最后审批时间 |
|---|---|---|---|---|---|

- 必填值：`所属项目`、`支付对象`
- 可空值：`所属公司`、`实际金额`、`详细说明`、`最后审批时间`
- `支付对象` 不存在于供应商库时会自动创建供应商。
- 导入弹窗未选择默认品类或默认需求提交人时，会在整文件校验通过后创建或复用默认值。

## 5. 字段格式规范

- 日期：`YYYY-MM-DD`，也支持 `YYYY/MM/DD`
- 布尔值：只接受 `是 / 否 / true / false / yes / no / 1 / 0`
- 税率：
  - `13%` 转换为 `0.13`
  - `13` 转换为 `0.13`
  - `0.13` 保持为 `0.13`
  - 空值为 null
  - 小于 0 或大于 100 为错误
- 报价：必须是数字
- 最小起订量：必须是整数或空

## 6. 错误报告格式

导入失败时返回结构化错误：

```ts
{
  success: false,
  message: string,
  errorCount: number,
  errors: [
    {
      row: number
      field: string
      value: string
      reason: string
      suggestion: string
    }
  ]
}
```

错误报告 CSV 字段：

| 行号 | 字段 | 原始值 | 错误原因 | 修改建议 |
|---|---|---|---|---|

示例：

| 行号 | 字段 | 原始值 | 错误原因 | 修改建议 |
|---|---|---|---|---|
| 2 | 供应商名称 |  | 供应商名称不能为空 | 请填写供应商名称；系统中不存在时会自动新建。 |
| 3 | 税率 | abc | 税率格式错误，无法解析为数字 | 请填写 13%、13、0.13，或留空。 |

## 7. 明确不支持

- 不支持 xlsx 导入
- 不支持 Word/PDF 导出
- 报价导入和供应商导入可自动创建缺失品类
- 报价导入可自动创建缺失供应商
- 不自动修复错误数据
- 不长期存储上传文件
