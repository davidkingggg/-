# CSV 导入导出模板 (CSV Templates)

固定导入导出格式，避免开发时字段混乱和解析错误。所有导入必须基于此结构。

## 4. 报价明细导入模板 (QuoteItem)
这是最常用的导入表，将外部结构化数据引入系统做对比。
| 报价单编号 | 报价单名称 | 报价文件路径 | 供应商名称 | 品类 | 报价日期 | 报价阶段 | 报价来源类型 | 对比规格标识 (compareKey) | 产品名称 | 型号规格 | 单位 | 报价 | 是否含税 | 税率 | 是否含运费 | 最小起订量 | 交期 | 付款条件 | 质保期 | 价格备注 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|

> **导入合并规则**：
> 1. 如果 CSV 中存在相同的“报价单编号”，则合并归为同一个 QuoteSheet。
> 2. 如果没有提供“报价单编号”，则按照 `供应商 + 品类 + 报价日期 + 报价阶段` 自动判断是否归为同一张报价单。

## 6. 字段格式规范
为了保证数据准确解析，CSV 填报请遵守以下格式约定：
- **日期**：`YYYY-MM-DD`（如：2026-05-01），也支持 `YYYY/MM/DD`
- **布尔值**：严格只接受以下值（不区分大小写）：
  - 真值：`是` / `true` / `yes` / `1`
  - 假值：`否` / `false` / `no` / `0`
  - **其他值（如空格、未知、N/A等）视为格式错误**，不会默认解析为 false
- **税率**：支持以下格式，系统自动统一转换为小数存储：
  - `13%` → 0.13
  - `13` → 0.13（大于 1 且 ≤ 100 的数字按百分数处理）
  - `0.13` → 0.13（0~1 之间直接作为小数）
  - 空值 → null
  - 小于 0 或大于 100 的数字 → 格式错误
- **是否愿意入驻平台**：`是 / 否 / 未确认`
- **合作意愿**：`强 / 一般 / 弱 / 未确认`
- **价格水平**：`高 / 中 / 低 / 未知`
- **推荐等级**：`A优先推荐 / B备选 / C暂不推荐 / 未评级`
- **报价阶段**：`初次报价 / 二次议价 / 最终确认价 / 量大优惠价`
- **风险点 (风险标签)**：如有多个标签，使用中文分号 `；` 分隔

## 7. CSV 导入事务模式说明
- 导入前先完整校验所有行
- **只要存在任何错误，本次导入全部失败，不写入任何部分数据**
- 前端展示错误行号和中文错误原因
- 如果"报价文件路径"非空，自动为对应 QuoteSheet 创建 Attachment 记录
