# 行政事项日历与归档设计

## 背景

行政事项当前是 `AdminTask` 个人归属数据，只展示给当前登录账号绑定的人员。新的设计目标是把行政事项从列表管理升级为日历可视化工作台，并把行政归档从全局归档管理中独立出来，方便日报、周报、月报和年报统计。

## 目标

- 行政事项默认使用“日历 + 右侧清单”的工作台形态。
- 支持用户自行创建个人行政待办。
- 支持只有日期的待办，也支持带开始时间和结束时间的日程。
- 支持常用重复规则：每日、每周、每月、每年，并预留以后做模板化重复事项。
- 在个人数据下新增“行政事项归档”，独立于全局归档管理。
- 行政事项归档支持按日、周、月、年查看和统计。
- 用户只能查看、恢复、归档、彻底删除自己的行政事项归档。
- 第一版不开放跨人指派，但预留创建人和负责人字段。

## 非目标

- 不把行政事项改造成完整协同待办平台。
- 第一版不做评论、审批、消息通知或附件。
- 第一版不允许管理员跨人彻底删除个人行政归档。
- 第一版不把采购、供应商开发等公共待办迁入行政日历。

## 信息架构

侧边栏“个人数据”下新增两个入口：

1. **行政事项**
   - 默认进入日历工作台。
   - 左侧为日历，右侧为选中日期或今日事项清单。
   - 用于创建、编辑、完成、归档日常行政事项。

2. **行政事项归档**
   - 独立于现有“归档管理”。
   - 只展示当前登录人员自己的行政归档数据。
   - 支持日、周、月、年视角切换。
   - 支持恢复和本人彻底删除。

首页和待办中心继续聚合“我的行政事项”，但只展示未归档、未关闭的当前事项。

## 数据模型

继续以 `AdminTask` 为核心，不新建通用 Todo 系统。建议补充字段：

- `taskDate`：事项所属日期，用于日历落点和报表统计。
- `startTime`：可选开始时间。
- `endTime`：可选结束时间。
- `recurrenceType`：重复规则，可取不重复、每日、每周、每月、每年。
- `recurrenceEndDate`：重复结束日期，可为空。
- `createdByPersonId`：创建人。
- `assigneePersonId`：负责人，第一版默认等于当前人员。

保留现有字段：

- `ownerPersonId`：继续作为个人数据归属口径。
- `dueDate`：旧数据来源，迁移时用于回填 `taskDate`。
- `isArchived` / `archivedAt`：用于行政事项归档。
- `completedAt`：用于完成统计。

彻底删除采用物理删除，且只允许在“行政事项归档”页面对本人归档记录执行。普通归档仍使用逻辑归档。

## 工作台行为

- 默认选中今天。
- 点击日历某一天，右侧展示当天事项。
- 新增事项默认带入当前选中日期。
- 普通待办可以只填日期。
- 会议、接待等事项可以填写开始时间和结束时间。
- 有时间的事项按开始时间排序。
- 无时间事项与有时间事项分组展示。
- 状态保留：未开始、进行中、已完成、暂停。
- 完成只改变状态并记录完成时间，不等于归档。
- 归档会从行政工作台和待办中心隐藏，并进入行政事项归档。

重复事项第一版保存常用规则，不自动生成无限未来记录。日历可根据规则展示近期实例；真正完成某一次时再记录该次实例，避免重复数据膨胀。

## 行政事项归档

归档页面支持四种视角：

- 日：查看某日事项、完成数、超期数、类型分布。
- 周：按自然周统计，周一到周日。
- 月：按自然月统计。
- 年：按自然年统计。

每条归档记录支持：

- 恢复：恢复后回到行政事项工作台。
- 彻底删除：需要二次确认，建议输入“确认彻底删除”。删除后无法恢复，且不再参与统计。

## 统计口径

- 日报：`taskDate` 落在当天的行政事项。
- 周报：`taskDate` 落在自然周内的行政事项。
- 月报：`taskDate` 落在自然月内的行政事项。
- 年报：`taskDate` 落在自然年内的行政事项。
- 已完成但未归档事项参与统计。
- 已归档事项参与行政归档统计。
- 被彻底删除事项不参与任何统计。
- 超期：`taskDate` 早于今天，状态不是已完成，且未彻底删除。
- 完成率：已完成数量 / 周期内事项总数。
- 类型分布：按会议、周报、办公采购、接待、证照资料、其他等类型统计。

## 权限与安全

- 未绑定人员的账号不能创建或查看行政事项。
- 普通用户只能访问自己的行政事项和行政归档。
- 用户只能彻底删除自己的行政归档记录。
- 彻底删除只在行政事项归档页面出现。
- 彻底删除需要二次确认。
- 管理员第一版不跨人删除个人行政归档。

## 验收标准

- 打开行政事项默认显示今天，左侧日历和右侧清单布局稳定。
- 新增只有日期的待办后，可在对应日期看到。
- 新增带开始和结束时间的事项后，可按时间排序显示。
- 日、周、月、年切换时，统计数量和事项列表口径一致。
- 完成事项后仍参与统计，但不再算超期。
- 归档事项后，从行政工作台隐藏，并进入行政事项归档。
- 从行政事项归档恢复后，事项重新回到工作台。
- 本人可以彻底删除自己的归档记录，删除后无法恢复，统计不再包含。
- A 用户看不到、删不了 B 用户的行政事项和归档。
- 未绑定人员账号不能创建或查看个人行政事项。
- 首页和待办中心仍只展示未归档、未关闭的“我的行政事项”。
