# 锅炉行业集成采购平台个人工作数据库

## Product Spec v1.0

### 1. 产品定位
这是一个**本地优先的个人工作数据库系统**，用于管理锅炉行业集成采购平台相关的：
- 品类开发
- 供应商开发
- 报价收集与对比
- 供应商评分
- 采购执行流程
- 老板汇报
- 销售/商务支持资料
- 日常行政事项

核心目标是解决实际工作中的三个问题：
1. **供应商和报价信息不再散乱**
2. **供应链开发和采购执行进度不丢失**
3. **可以随时整理出给老板、销售、商务使用的资料**

### 2. 第一版核心原则
#### 2.1 以品类为主线
系统的主线：**品类 → 供应商 → 报价 → 评分 → 流程 → 汇报**

#### 2.2 供应商开发流程和采购执行流程分开
- **供应商开发流程**：管理供应商是否值得纳入平台、是否完成考察/报价等。
- **采购执行流程**：管理具体采购需求、参数确认、报价、合同、付款、到货验收等。

#### 2.3 报价采用“报价单 + 报价明细”结构
- **报价单 QuoteSheet**：记录一次报价的来源（如微信、PDF、Excel、图片等）。
- **报价明细 QuoteItem**：将报价单中的内容逐条结构化，以便于对比。

#### 2.4 人员单独建表
内部人员（老板、销售、商务、需求提交人等）单独建表，支持按人员筛选和跟踪进度。

#### 2.5 行政事项独立管理
行政事项不与供应链事项混杂，但可在首页仪表盘和待办中心中展示摘要。

### 3. 用户角色
#### 3.1 当前用户（主要操作者）
- 录入供应商、收集报价、做评分、管理流程、生成汇报资料、管理行政杂事。

#### 3.2 后续可能用户（预留空间）
- **老板**：查看重点品类进展、推荐供应商、决策事项、风险等。
- **销售人员**：查看推荐供应商、品类优势、报价对比、销售话术。
- **商务/采购协同人员**：跟进采购执行、合同发票状态等。

### 4. 核心功能模块
#### 4.1 首页仪表盘
- **平台主线工作**：品类/供应商统计、本周采购/开发事项、决策事项、最近更新等。
- **行政事项**：本周行政事项统计、未完成/超期事项摘要。

### 5. 页面结构（第一版主菜单）
1. 首页仪表盘
2. 品类中心
3. 供应商库
4. 报价管理
5. 报价对比
6. 供应商评分
7. 调研/考察记录
8. 供应商开发看板
9. 采购执行看板
10. 待办中心
11. 老板汇报
12. 销售/商务资料
13. 行政事项
14. 人员管理
15. 数据导入导出
16. 系统设置

### 6. 待办中心设计
统一展示各来源待办，分区域显示：
- 平台主线待办
- 采购执行待办
- 老板决策事项
- 销售配合事项
- 行政事项

### 7. 老板汇报页（自动汇总）
- 本周供应链开发进展
- 当前重点品类进度
- 需要决策事项
- 风险和异常
- 支持复制为 Markdown / 导出 CSV。

### 8. 销售/商务资料模块
定位为“正式风格资料库”，辅助生成产品和供应商的核心卖点、优势、风险提示等。

### 9. CSV 导入导出
支持供应商、报价单、报价明细的导入，以及供应商、报价对比的导出。

### 10. 第一版不做或后置的功能

- 多人实时协作
- 文件上传（第一版只记录本地路径）
- AI 自动评分
- 手机端适配
- 复杂统计图表
- 拖拽看板（先用下拉修改阶段）
- 自动提醒通知
- 内网服务器部署
- Word/PDF 汇报导出
