# 测试计划 (Test Plan)

本测试计划用于在每个开发阶段结束后，进行手动功能的全面检查，确保不遗漏核心用例。

## 1. 基础页面与路由测试
- [ ] 系统能否在本地成功运行并打开首页
- [ ] 左侧导航栏的每一个菜单是否都能正常点击并跳转
- [ ] 各页面是否存在明显的 404 或白屏错误

## 2. 品类模块测试
- [ ] 能否新增品类
- [ ] 能否编辑品类
- [ ] 能否设置是否优先推广
- [ ] 品类详情页能否看到该品类下的供应商、报价、评分和流程

## 3. 人员管理测试
- [ ] 能否新增人员
- [ ] 能否编辑人员
- [ ] 能否停用人员
- [ ] 采购执行流程能否选择需求提交人、负责人、销售配合人

## 4. 供应商模块测试
- [ ] 能否成功新增供应商
- [ ] 能否成功编辑供应商信息
- [ ] 能否将供应商进行逻辑归档（删除）并确认不在列表中直接显示
- [ ] 供应商能否正确绑定对应的主品类
- [ ] 一个供应商能否添加多个联系人
- [ ] 能否通过名称正确搜索供应商
- [ ] 能否按品类和风险标签正确筛选供应商
- [ ] 页面刷新后，新增或修改的供应商数据是否依旧存在

## 5. 供应商开发流程测试
- [ ] 能否新增供应商开发流程
- [ ] 能否修改开发阶段
- [ ] 能否标记需要销售配合
- [ ] 能否标记需要老板决策
- [ ] 待办中心能否聚合开发流程事项

## 6. 报价模块测试
- [ ] 能否成功新增一次报价单（注意附件路径单独在附件模块管理）
- [ ] 能否在同一张报价单下，添加多条报价明细
- [ ] 报价明细是否正确关联了供应商和品类
- [ ] 能否正确导入 CSV 格式的报价数据
- [ ] 报价导入模板能否下载，且中文表头在 Excel 中正常显示
- [ ] 报价 CSV 缺少必填字段时，是否整文件失败且不写入任何数据
- [ ] 报价 CSV 中供应商不存在时，是否显示中文错误和修改建议
- [ ] 报价 CSV 中品类不存在时，是否显示中文错误和修改建议
- [ ] 税率 `13%`、`13`、`0.13` 是否都能正确解析
- [ ] 非法布尔值是否被拒绝，并提示允许值
- [ ] 报价 CSV 成功导入后，是否正确创建 QuoteSheet、QuoteItem 和报价文件路径附件记录
- [ ] 同一 `quoteNumber` 下供应商、品类、报价日期、报价阶段或报价来源类型冲突时，是否整文件失败且不写入任何数据
- [ ] CSV 中的 `quoteNumber` 与系统已有报价单的关键字段冲突时，是否整文件失败且返回中文错误和修改建议
- [ ] 导入失败时，错误报告表格是否显示行号、字段、原始值、错误原因、修改建议
- [ ] 导入失败时，错误报告 CSV 是否可下载
- [ ] 能否正确导出报价数据为 CSV 格式

## 7. 报价对比测试
- [ ] 能否在对比页正确筛选某个品类
- [ ] 能否通过 `compareKey`（对比规格标识）准确筛选同类产品/型号
- [ ] 系统是否自动且正确地计算出最低价、最高价、平均价
- [ ] 界面是否直观展示同规格下多供应商的横向对比

## 8. 采购流程与待办测试
- [ ] 能否成功新增采购执行事项
- [ ] 能否通过下拉或其他方式正确修改当前流程阶段
- [ ] 能否正确标记“需要老板决策”状态
- [ ] 采购执行事项的金额、合同、付款等字段能否正常保存
- [ ] 供应商详情页中，能否清晰看到该供应商关联的所有采购记录
- [ ] 待办中心能否正确聚合展示（采购/开发/行政）即将到期或需决策的事项

## 9. 销售/商务资料测试
- [ ] 能否新增销售/商务资料
- [ ] 能否按品类筛选资料
- [ ] 能否复制正式资料正文
- [ ] 能否导出为 CSV 或 Markdown
- [ ] 导出的 CSV 是否使用统一中文表头、UTF-8 BOM 和标准 CSV 转义

## 9A. 数据导入导出工具测试
- [ ] `/data` 页面能否正常打开
- [ ] `/data` 页面能否下载报价明细导入模板
- [ ] `/data` 页面能否下载供应商导入预研模板
- [ ] 报价管理页能否下载报价明细导入模板
- [ ] 模板 CSV 是否包含 UTF-8 BOM，且中文表头在 Excel 中正常显示
- [ ] 报价 CSV 导出是否正常
- [ ] 报价对比 CSV 导出是否正常
- [ ] 老板汇报 CSV 导出是否正常
- [ ] 销售/商务资料 CSV 导出是否正常
- [ ] 销售/商务资料 Markdown 导出是否正常

## 10. 附件模块测试
- [ ] 能否给供应商添加附件路径
- [ ] 能否给报价单添加附件路径
- [ ] 附件路径是否不会写死在代码中
- [ ] 归档主记录后，附件是否仍能查询或保留

## 11. 其他核心功能验证
- [ ] 能否对供应商+品类进行评分，并自动计算总分/评级
- [ ] 能否成功新增考察记录，并在详情页可见
- [ ] 行政事项的增删改查是否正常，且没有与供应链业务混杂
- [ ] 首页老板汇报页的数据汇总（本周进展、重点品类数量）是否计算无误
