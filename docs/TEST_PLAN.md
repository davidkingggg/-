# 测试计划 (Test Plan)

本测试计划用于在每个开发阶段结束后，进行手动功能的全面检查，确保不遗漏核心用例。

> **Phase 9C 回归测试范围说明 (2026-05-11)：**
> 本轮回归已完成两层验证：
> - API/数据层：覆盖全部 48 个端点 + 23 条页面路由 + 6 组 CSV 回归样例
> - 浏览器层：补做关键页面交互、Toast、弹窗、剪贴板、导出下载与本地备份恢复重启后的 smoke test
> 已勾选 `[x]` 的项表示对应层级已实际验证。
> 仍未直接覆盖、保留 `[ ]` 的重点项：
> - Excel 打开 CSV 的中文表头显示
> - 供应商详情页附件路径入口（当前浏览器回归失败，见第 14 节）
