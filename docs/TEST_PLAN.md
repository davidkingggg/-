# 测试计划 (Test Plan)

本测试计划用于在每个开发阶段结束后，进行手动功能的全面检查，确保不遗漏核心用例。

## 1. 基础页面与路由测试
- [ ] 系统能否在本地成功运行并打开首页
- [ ] 左侧导航栏的每一个菜单是否都能正常点击并跳转
- [ ] 各页面是否存在明显的 404 或白屏错误

## 2. 品类模块测试
- [ ] 能否新增品类
- [ ] 能否编辑品类
- [ ] 能否设置是否优先推广
- [ ] 品类详情页能否看到该品类下的供应商、报价、评分和流程

## 3. 人员管理测试
- [ ] 能否新增人员
- [ ] 能否编辑人员
- [ ] 能否停用人员
- [ ] 采购执行流程能否选择需求提交人、负责人、销售配合人

## 4. 供应商模块测试
- [ ] 能否成功新增供应商
- [ ] 能否成功编辑供应商信息
- [ ] 能否将供应商进行逻辑归档（删除）并确认不在列表中直接显示
- [ ] 供应商能否正确绑定对应的主品类
- [ ] 一个供应商能否添加多个联系人
- [ ] 能否通过名称正确搜索供应商
- [ ] 能否按品类和风险标签正确筛选供应商
- [ ] 页面刷新后，新增或修改的供应商数据是否依旧存在

## 5. 供应商开发流程测试
- [ ] 能否新增供应商开发流程
- [ ] 能否修改开发阶段
- [ ] 能否标记需要销售配合
- [ ] 能否标记需要老板决策
- [ ] 待办中心能否聚合开发流程事项

## 6. 报价模块测试
- [ ] 能否成功新增一次报价单（注意附件路径单独在附件模块管理）
- [ ] 能否在同一张报价单下，添加多条报价明细
- [ ] 报价明细是否正确关联了供应商和品类
- [ ] 能否正确导入 CSV 格式的报价数据
- [ ] 报价导入模板能否下载，且中文表头在 Excel 中正常显示
- [ ] 报价 CSV 缺少必填字段时，是否整文件失败且不写入任何数据
- [ ] 报价 CSV 中供应商不存在时，是否显示中文错误和修改建议
- [ ] 报价 CSV 中品类不存在时，是否显示中文错误和修改建议
- [ ] 税率 `13%`、`13`、`0.13` 是否都能正确解析
- [ ] 非法布尔值是否被拒绝，并提示允许值
- [ ] 报价 CSV 成功导入后，是否正确创建 QuoteSheet、QuoteItem 和报价文件路径附件记录
- [ ] 同一 `quoteNumber` 下供应商、品类、报价日期、报价阶段或报价来源类型冲突时，是否整文件失败且不写入任何数据
- [ ] CSV 中的 `quoteNumber` 与系统已有报价单的关键字段冲突时，是否整文件失败且返回中文错误和修改建议
- [ ] 导入失败时，错误报告表格是否显示行号、字段、原始值、错误原因、修改建议
- [ ] 导入失败时，错误报告 CSV 是否可下载
- [ ] 能否正确导出报价数据为 CSV 格式

## 7. 报价对比测试
- [ ] 能否在对比页正确筛选某个品类
- [ ] 能否通过 `compareKey`（对比规格标识）准确筛选同类产品/型号
- [ ] 系统是否自动且正确地计算出最低价、最高价、平均价
- [ ] 界面是否直观展示同规格下多供应商的横向对比

## 8. 采购流程与待办测试
- [ ] 能否成功新增采购执行事项
- [ ] 能否通过下拉或其他方式正确修改当前流程阶段
- [ ] 能否正确标记“需要老板决策”状态
- [ ] 采购执行事项的金额、合同、付款等字段能否正常保存
- [ ] 供应商详情页中，能否清晰看到该供应商关联的所有采购记录
- [ ] 待办中心能否正确聚合展示（采购/开发/行政）即将到期或需决策的事项

## 8D-3. CSV 导入导出回归样例库测试
- [ ] 执行回归脚本前，先运行 `npm run prisma:seed`，确保本地开发数据库处于可预期状态
- [ ] 明确成功导入样例会写入本地开发数据库；执行后如需恢复干净状态，可重新运行 `npm run prisma:seed` 或恢复数据库备份
- [ ] `scratch/import_quote_success_regression.csv` 能否成功导入，并创建 2 条 QuoteSheet、3 条 QuoteItem、1 条 Attachment
- [ ] 成功样例能否覆盖固定 `quoteNumber` 多行合并、无编号报价自动归组、报价文件路径附件创建
- [ ] 成功样例能否覆盖供应商、品类、报价日期、报价阶段、报价来源类型、compareKey、产品名称、型号规格、单位、报价、最小起订量、交期、付款条件、质保期、价格备注
- [ ] 成功样例能否覆盖布尔值 `是`、`否`、`true`、`1` 和税率 `13%`、`0.13`、`13`
- [ ] 固定 `quoteNumber` 成功样例重复执行前，是否已重新 seed 或恢复数据库；不要为重复执行修改导入业务逻辑
- [ ] `scratch/import_quote_fail_validation_regression.csv` 能否验证格式类错误整文件失败，且不产生 QuoteSheet、QuoteItem、Attachment 部分写入
- [ ] 格式失败样例能否覆盖缺少必填 `compareKey`、非法布尔值、非法税率、非法报价数字、非法最小起订量
- [ ] `scratch/import_quote_fail_reference_regression.csv` 能否验证引用/冲突类错误整文件失败，且不产生 QuoteSheet、QuoteItem、Attachment 部分写入
- [ ] 引用/冲突失败样例能否覆盖不存在供应商、不存在品类、与系统已有 `quoteNumber` 关键字段冲突
- [ ] `scratch/test_csv_api.ts` 能否通过 `process.env.BASE_URL ?? "http://localhost:3000"` 调用本地服务，并输出样例用途、预期结果、失败不写入验证结果
- [ ] CSV 样例文件本身是否没有注释行，样例用途、字段覆盖、预期结果仅写入本文档或脚本输出
- [ ] 本阶段是否未提交未跟踪的 `scratch/export_test.csv`
- [ ] 供应商 CSV 是否仍仅提供预研模板，未开放正式导入
- [ ] 本阶段是否未新增导入类型、未修改 CSV 导入业务逻辑、未修改 Prisma schema、未新增 migration、未修改 seed、未进入第 9 阶段

## 9. 销售/商务资料测试
- [ ] 能否新增销售/商务资料
- [ ] 能否按品类筛选资料

- [ ] `/data` 页面能否下载报价明细导入模板
- [ ] `/data` 页面能否下载供应商导入预研模板
- [ ] 报价管理页能否下载报价明细导入模板
- [ ] 模板 CSV 是否包含 UTF-8 BOM，且中文表头在 Excel 中正常显示
- [ ] 报价 CSV 导出是否正常
- [ ] 报价对比 CSV 导出是否正常
- [ ] 老板汇报 CSV 导出是否正常
- [ ] 销售/商务资料 CSV 导出是否正常
- [ ] 销售/商务资料 Markdown 导出是否正常

## 9B. 数据质量检查导出测试
- [ ] `/data-quality` 页面能否正常打开
- [ ] `/api/data-quality` 能否正常返回 JSON
- [ ] `/api/data-quality/export` 能否正常返回 CSV
- [ ] 数据质量 CSV 是否包含 UTF-8 BOM，且中文在 Excel 中正常显示
- [ ] 数据质量 CSV 响应头是否包含 `Content-Type: text/csv; charset=utf-8`、`Content-Disposition: attachment; filename="data-quality-export.csv"` 和 `Cache-Control: no-store`
- [ ] `severity` 筛选后页面和 CSV 导出口径是否一致
- [ ] `check` 筛选后页面和 CSV 导出口径是否一致
- [ ] `categoryId` 筛选后页面和 CSV 导出口径是否一致
- [ ] `limit` 限制下的 `count`、`returnedCount`、`hasMore` 是否和 CSV 中“当前检查项”字段一致

- [ ] 导出过程是否不写入数据库、不新增 migration

## 9C. 本地备份恢复运维基线测试
- [ ] `/backup` 页面能否正常打开
- [ ] 页面是否明确说明本功能仅备份和恢复本地 SQLite 数据库
- [ ] 页面是否明确说明不包含附件物理文件、系统环境、Node 依赖或外部文档
- [ ] `/api/backups` 能否正常返回数据库状态和备份列表 JSON
- [ ] 创建普通备份是否正常，且备份文件名符合 `boiler-procurement-db-YYYYMMDD-HHMMSS-ms.sqlite`
- [ ] 备份列表是否展示文件名、类型、用途说明、大小、创建时间和修改时间
- [ ] 恢复指定备份是否正常
- [ ] 恢复前是否自动创建 `before-restore` 安全备份
- [ ] 非法文件名是否被拦截
- [ ] 路径穿越文件名是否被拦截
- [ ] 未输入或输错确认短语时，恢复操作是否无法执行或被后端拒绝
- [ ] 备份与恢复相关错误提示是否为中文
- [ ] 恢复弹窗和恢复成功提示是否明确要求停止并重新启动本地服务后再继续使用
- [ ] 本阶段是否未新增 dry-run、删除备份、下载备份、定时备份、自动清理或云备份能力
- [ ] 本阶段是否未新增 migration、未修改 Prisma schema、未修改 seed、未写入第 9 阶段功能
